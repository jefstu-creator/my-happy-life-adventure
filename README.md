# My Happy Life Adventure — child-friendly remake

This is a simple, browser-based choice game inspired by the uploaded **Life to a Million** project. It replaces the original financial simulation with a gentle four-round adventure for young children.

## What changed
- Big, colourful picture buttons with short labels.
- One simple decision per round; no wrong answers, money, debt, investments, ads or failure states.
- Four short themes: play, kindness, learning, and caring for a town.
- Stars, a growing town scene, small animations and a cheerful finish screen.
- Optional first name; no account or internet connection required for gameplay.
- Responsive layout for phones, tablets and computers.
- Keyboard support, visible focus states and reduced-motion support.

## Run it
Open `index.html` in a browser. There are no build steps or dependencies.

## Deploy to Vercel
1. Upload the three files (`index.html`, `styles.css`, `game.js`) to a GitHub repository.
2. Import the repository into Vercel.
3. Choose **Other** as the framework preset.
4. Leave build and output commands blank and deploy.

The game does not store a child's name or gameplay in a server or browser storage. The optional name stays in memory while the page is open.
